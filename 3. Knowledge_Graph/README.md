# Knowledge Graphs

## Objective

To study Knowledge Graphs and explore tools used for building and managing Knowledge Graphs.

---

## What is a Knowledge Graph?

A Knowledge Graph (KG) is a structured representation of knowledge in which entities are connected through relationships.

It stores information in the form:

Entity → Relationship → Entity

Example:

Tourist → visits → Charminar

Charminar → located_in → Hyderabad

Hyderabad → famous_for → Biryani

---

## Components of a Knowledge Graph

### 1. Entities

Objects or concepts.

Examples:

- Tourist
- City
- Hotel
- Restaurant

### 2. Relationships

Connections between entities.

Examples:

- visits
- located_in
- serves
- stays_at

### 3. Attributes

Properties of entities.

Examples:

City:
- Population
- Country

Hotel:
- Price
- Rating

---

## Example Travel Knowledge Graph

Tourist → visits → Charminar

Charminar → located_in → Hyderabad

Tourist → stays_at → Hotel

Tourist → eats → Biryani

Biryani → served_at → Restaurant
