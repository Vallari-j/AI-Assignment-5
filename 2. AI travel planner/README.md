# AI Based Travel Planner

## Objective

Develop an AI-based Travel Planner that reuses
existing knowledge bases to generate
personalized travel recommendations.

---

## Knowledge Bases Used

1. Tourist Places Knowledge Base
2. Food Recommendation Knowledge Base
3. Travel Cost Knowledge Base

---

## Inputs

- Destination City
- Number of Days
- User Interest

---

## AI Features

### Personalized Planning

Generates itinerary based on user interests:

- Historical
- Nature

### Food Recommendation

Suggests famous local foods.

### Cost Assessment

Estimates total travel cost.

---

## Example

Input:

City = Hyderabad
Days = 2
Interest = Historical

Output:

- Tourist attractions
- Food recommendations
- Estimated cost

---

## Technologies Used

- Python
- JSON Knowledge Bases
