# Bayesian Networks

## Objective

To explore Bayesian Networks for modelling uncertainty, problem representation, and inferencing.

---

## What is a Bayesian Network?

A Bayesian Network (BN) is a probabilistic graphical model that represents random variables and their dependencies using a directed acyclic graph (DAG).

Nodes represent variables.

Edges represent probabilistic dependencies.

---

## Example

Weather Prediction

Cloudy → Rain → Wet Grass

Cloudy influences Rain.

Rain influences Wet Grass.

---

## Advantages

- Handles uncertainty
- Supports probabilistic reasoning
- Predicts missing information
- Easy to visualize dependencies

---

## Applications

- Medical diagnosis
- Weather forecasting
- Risk analysis
- Spam filtering
- Recommendation systems
